# Stage numbering runs from the pad upwards

Stage one is the stage that lights on the pad; later stages count upwards in
firing order, whatever their position in the drawing.

Test reports and telemetry both use this numbering, so a report that counts
downwards from the nose has to be relabelled before it is filed.
